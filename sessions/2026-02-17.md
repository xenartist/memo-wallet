### 1. Portfolio 资产显示扩展

#### 1.1 问题背景

原有 Portfolio 页面只显示 XNT 和 SOL 两种代币，无法显示钱包中已持有的其他 SPL 代币（如 USDC.X、其他 Token-2022 代币等）。

#### 1.2 解决方案

实现自动发现钱包在 X1 和 Solana 两条链上持有的所有 SPL 代币：

- **X1 链**:

  - 原生 XNT: `getBalance` RPC
  - SPL tokens (TOKEN_PROGRAM): `getTokenAccountsByOwner` with `{ programId: TOKEN_PROGRAM }`
  - SPL tokens (TOKEN_2022_PROGRAM): `getTokenAccountsByOwner` with `{ programId: TOKEN_2022_PROGRAM }`

- **Solana 链**:
  - 原生 SOL: `getBalance` RPC
  - SPL tokens (TOKEN_PROGRAM): 同上
  - SPL tokens (TOKEN_2022_PROGRAM): 同上

#### 1.3 代币图标获取策略

1. 本地已知图标 (XNT, SOL 使用本地图片资源)
2. `KNOWN_TOKEN_METADATA` 中预设的 logo_uri
3. 从链上 Token-2022 metadata 扩展获取 URI -> fetch JSON -> image 字段
4. 首字母占位符 (圆形背景 + symbol 首字母)

#### 1.4 代币排序

- 原生代币 (XNT, SOL) 始终在最前
- SPL 代币按余额 (rawBalance) 降序排列

## 重要规则总结

### 代币发现

- 使用 `getTokenAccountsByOwner` 查询钱包所有 SPL 代币余额
- 需要分别查询 `TOKEN_PROGRAM` 和 `TOKEN_2022_PROGRAM` 两个 programId
- 需要分别在 X1 和 Solana 两条链上查询

### 文件拆分原则

- `rpc.ts`: 所有区块链共享的基础工具 (RPC 调用、编解码、常量)
- `portfolio.ts`: Portfolio/资产相关逻辑 (代币发现、余额查询)
- `swap.ts`: Swap/交易相关逻辑 (池查询、价格计算、交易指令)
- `App.tsx`: 仅包含 UI 渲染和状态管理，调用各模块函数

### 多链支持

- X1 RPC: `https://rpc.mainnet.x1.xyz`
- Solana RPC: `https://api.mainnet-beta.solana.com`
- 工具函数需支持 `rpcUrl` 参数
