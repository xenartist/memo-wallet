## 完成的工作

### 1. xDEX API 集成：简化代币查询

#### 1.1 背景

原有实现使用 6 次区块链 RPC 调用来获取钱包代币：

- X1: getBalance + 2× getTokenAccountsByOwner
- Solana: getBalance + 2× getTokenAccountsByOwner

发现 xDEX API 可以一次性获取钱包所有代币信息，大幅简化实现。

#### 1.2 xDEX API

```
GET https://api.xdex.xyz/api/xendex/wallet/tokens?wallet_address={addr}&network=X1%20Mainnet
```

返回字段：

- mint, amount, decimals, ui_amount
- symbol, name, imageUrl
- is_lp_token, volume_usd

#### 1.3 实现变更

**src/rpc.ts** - 新增函数：

```typescript
export interface XDEXToken {
  mint: string;
  amount: number;
  decimals: number;
  ui_amount: number;
  symbol: string;

export async function fetchXDEXWalletTokens(
  walletAddress: string,
  network: 'X1 Mainnet' | 'Solana Mainnet',
```

**src/portfolio.ts** - 重构：

- 删除 6 次 RPC 调用逻辑

- 过滤 `is_lp_token=true` 的 LP 代币
- 简化 `PortfolioToken` 接口：移除 `usdPrice`, `usdValue`
- 代币排序：原生代币优先 → 按余额降序

**App.tsx** - 适配更新：

- 移除 usdValue 相关渲染逻辑
- 简化为只显示代币数量和符号

#### 1.4 原生代币识别

xDEX API 返回的原生代币 mint 为 `111111111111111111111111111111111111111111`（非 null），需特殊处理：

```typescript
const NATIVE_MINT = '111111111111111111111111111111111111111111';

function isNativeToken(mint: string | null): boolean {
  return mint === null || mint === NATIVE_MINT;
}
```

排序时：XNT (X1) → SOL (Solana) → 其他 SPL 代币

## 重要规则总结

### 代币发现 (更新)

- 优先使用 xDEX API: `https://api.xdex.xyz/api/xendex/wallet/tokens`
- 支持网络: `X1 Mainnet`, `Solana Mainnet`
- 过滤 LP 代币: `is_lp_token === true`
- 原生代币 mint: `111111111111111111111111111111111111111111`

### 文件拆分原则

- `rpc.ts`: 所有区块链共享的基础工具 (RPC 调用、编解码、常量) + xDEX API 调用
- `portfolio.ts`: Portfolio/资产相关逻辑 (代币发现、余额查询)
- `swap.ts`: Swap/交易相关逻辑 (池查询、价格计算、交易指令)
- `App.tsx`: 仅包含 UI 渲染和状态管理，调用各模块函数

### 多链支持

- X1 RPC: `https://rpc.mainnet.x1.xyz`
- Solana RPC: `https://api.mainnet-beta.solana.com`
- xDEX API: `https://api.xdex.xyz/api/xendex/wallet/tokens`
