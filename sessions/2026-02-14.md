## Technical Notes

- opencode-dcp: Session-internal token optimization, not suitable for cross-session persistence
- OpenClaw Memory: Uses compaction to compress conversation history, stores as Markdown
- QMD: Local search/indexing tool (BM25 + vectors), overkill for small projects
- Skill vs Plugin: Skill relies on LLM interpretation, plugin executes code directly
